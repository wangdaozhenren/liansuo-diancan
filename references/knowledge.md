# 连锁品牌点餐红包助手 · 平台规则与叠加指南

> 覆盖品牌：肯德基、麦当劳、汉堡王、必胜客、华莱士、星巴克（品牌官方在线点餐/自助下单）。

## 一、各品牌红包规则

### 肯德基（KFC）
- **领取条件**：新客首单立减、大神卡/宅急送会员专享券；老客可领疯狂星期四、桶餐券
- **使用门槛**：多为指定套餐/单品立减券，限App在线点餐；部分券限堂食或自提
- **有效期**：券码多为7~30天，疯狂星期四限每周四当天
- **是否可叠加**：券可与会员价叠加，一般不与外卖平台大额券重复

### 麦当劳（McDonald's）
- **领取条件**：新客首单低价、麦麦会员/麦乐送专享券；老客每周优惠券、套餐券
- **使用门槛**：限指定套餐组合，部分券限早餐时段或全天
- **有效期**：电子券当周有效或短期有效
- **是否可叠加**：券与会员积分可叠加，与外卖平台红包互斥

### 汉堡王（Burger King）
- **领取条件**：新客皇堡套餐券、老客狠霸王牛堡套餐立减、每周特惠
- **使用门槛**：限指定套餐，自提/外送分券，注意使用方式
- **有效期**：券码7~15天
- **是否可叠加**：品牌券与会员价可叠，跨平台红包不叠加

### 必胜客（Pizza Hut）
- **领取条件**：新客披萨买一送一/立减、老客亲子套餐、下午茶套餐券
- **使用门槛**：限指定披萨/套餐，部分券限堂食
- **有效期**：券码15~30天，节假日可能不可用
- **是否可叠加**：券可与会员折扣叠加，节假日/特殊时段受限

### 华莱士
- **领取条件**：新客全家桶券、老客单品立减、多件套特惠
- **使用门槛**：人均低、套餐为主，限在线自提
- **有效期**：券码7~30天
- **是否可叠加**：套餐券多为一口价，不与其他券叠加

### 星巴克（Starbucks）
- **领取条件**：新客首杯券、星会员买赠、咖啡券/星礼包
- **使用门槛**：限指定饮品/中杯以上，部分限门店核销
- **有效期**：电子券多为30天，季节限定可能短期有效
- **是否可叠加**：券与星积分、银行信用卡咖啡活动可叠加

## 二、红包叠加逻辑

- **叠加顺序**：品牌券码 → 会员价/会员日折扣 → 支付优惠（信用卡/移动支付）
- **自提比外送省**：品牌App自提常免外送费、券更全，顺路取餐最划算
- **套餐比单点省**：券多绑套餐，单人/双人套餐比单点便宜（示例20~30%，以实时为准）
- **品牌券≠外卖券**：品牌官方券走品牌App，美团/饿了么红包走外卖平台，同单一般不互叠

## 三、品类专属知识要点

### 3.1 品牌日历（知识卡核心）
- **肯德基疯狂星期四**：每周四固定桶餐/单品特惠，是一周力度最大的时点
- **麦当劳会员日/每周券**：App内每周一更新优惠券包，常含早餐/套餐券
- **星巴克会员日/买赠**：会员活动和咖啡券包，常喝可买星礼包
- **汉堡王/必胜客**：每周/每月固定特惠日，下单前先看本周品牌App活动
- 记住各品牌"固定省钱日"，比随手点单省得多

### 3.2 早餐券与下午茶时段券
- **早餐券**：限早间时段（如6:00-10:30），麦当劳/肯德基早餐套餐券最便宜，别午间用不了
- **下午茶券**：限下午时段（如14:00-17:00），必胜客/星巴克下午茶套餐券
- 时段券和全天券不通用，买券前看清"可用时段"，买错时段用不了
- 错峰用餐用时段券最香，高峰正餐时段用全天套餐券

### 3.3 自提 vs 外送
- **自提**：免配送费、券更全，顺路取餐最划算
- **外送**：另付配送费，部分自提券不能用于外送
- 品牌App自提常比美团/饿了么外送便宜，除非外送红包特别大

### 3.4 机场/高铁门店不参与
- 机场、高铁站、服务区等交通枢纽门店常**不参与**品牌优惠活动，价格也更高
- 机场店买早餐别指望用App券，下单前在门店列表确认是否可用
- 旅游景区店同理，券可用范围窄

## 四、新客与老客区别

- **新客专享**：各品牌首单立减、首杯/首份低价券，力度最大，一个账号一次
- **老客可领**：每周/每月固定券、会员日、桶餐/套餐特惠
- **新老客通用**：品牌App内每周优惠券包、限时秒杀单品
- 新客券一个品牌一个账号一次，别浪费在原价单上

## 五、避坑指南

1. **券买错时段**：早餐券午间用不了、周四券非周四用不了，下单前看"可用时段"
2. **品牌券不通用**：肯德基券不能在麦当劳用，别领错品牌
3. **机场/高铁店不参与**：枢纽门店常排除活动，下单前确认门店列表
4. **外送费另算**：自提券免配送费，外送另付，别以为券价就是总价
5. **券不找零不兑现**：券超额补差价，不找零不兑现；核销后按各品牌退换政策
